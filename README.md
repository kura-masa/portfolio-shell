# portfolio-shell

3人のポートフォリオサイトの**土台（シェル）**。
`festival-kiosk` のゲーム選択画面から、祭り運営に依存する部分を落として Web公開向けに作り直したもの。

**中身は仮置きです。** 並べるプロダクト・文言・映像・誰が作ったかは未確定なので、
そのまま公開せず、実物に差し替えてから使ってください（→ 最後の「まだ埋まっていないところ」）。

---

## 動かす

ビルドは要りません。静的サーバーで開くだけです。

```
python3 -m http.server 4173
```

→ http://localhost:4173

`file://` で直接開くと、フォントと映像が読めません（必ずサーバー経由で）。

## 中身を書き換える

`index.html` の中の **`PRODUCTS` 配列を書き換えるだけ**で、並びも中身も変わります。
それ以外を触る必要はありません。

```js
{
  id: "stg",
  name: "シューティング",          // 左リストと見出し。ドット書体で出るので短く
  sub: "うちゅうを まもる",          // 一行の添え書き
  tag: "ゲーム",                    // 種類のラベル
  by: "制作: 谷口",                 // ⚠️ 分からないものは【要確認】のままに
  icon: ICON_STG,                  // 左のドット絵
  scene: SCENE_BLANK,              // プレビューが読めなかったときの仮絵
  ratio: "256 / 240",              // プレビュー枠の比率（サイトなら "16 / 9"）
  demo: "./demos/stg.webm",        // ループ再生する映像。無ければ省略
  poster: "./previews/xxx.png",    // 映像が無いときの静止画。無ければ scene が出る
  desc: "説明文。改行はそのまま出ます",
  actions: [
    { label: "▶ あそぶ", href: "./games/stg/index.html", primary: true },
    { label: "ソースを見る", href: "" }   // href が空だと「押せない見た目」になる
  ]
}
```

プレビューは **映像 → 静止画 → ドット絵** の順に落ちていきます。
映像が無いプロダクトを混ぜても画面は壊れません。

### 操作

- マウスのある画面: **ホバーで選ぶ・クリックで開く**
- タッチ: **1回目のタップで選ぶ・2回目で開く**（キオスクと同じ）
- キーボード: `↑↓` で選ぶ、`Enter` で開く
- 900px 未満では1カラムに畳んで、ページごとスクロールします

## ゲームを置く

`games/` は空です（ビルド成果物なので Git に入れていません）。
2つのリポジトリを隣に置いて、同期スクリプトを回してください。

```
cd ~/dev
git clone https://github.com/medaka333/famicongame.git
git clone https://github.com/medaka333/animalVS.git
cd portfolio-shell && ./sync-games.sh
```

**この2つは性質がまったく違います。**

| | famicongame（STG・ブロック崩し） | animalVS（タワーバトル） |
|---|---|---|
| 中身 | Godot 4 | TypeScript + Vite + matter-js |
| Web版ビルド | **リポジトリにコミット済み**。clone だけで手に入る | **入っていない。毎回ビルドが要る** |
| ビルド | Godot エディタからエクスポートしたときだけ | `npx vite build --config apps/game/vite.config.ts --base=./` |
| 落とし穴 | — | **`--base=./` を忘れると assets が絶対パスになり黒画面**。`sync-games.sh` が検査して止めます |

タワーバトルには**別の公開版**もあります（`human-stack-battle-game.pages.dev`）。
自分でホストせず、そちらへリンクする選択肢もあります。どちらにするかは未決定です。

## 公開するときに効くこと（実測）

**1. Godotのゲームに特別なサーバー設定は要りません。**
`export_presets.cfg` が `variant/thread_support=false` なので SharedArrayBuffer を使いません。
つまり **COOP / COEP ヘッダの設定が不要**で、普通の静的ホスティングにそのまま置けます。
（Godot の Web公開で最初にハマる場所ですが、この設定のおかげで最初から踏みません）

**2. ただし重い。圧縮配信は必須です。**

| | 実測 |
|---|---|
| `index.wasm`（1本） | **39.5 MB** |
| gzip -6 をかけたとき | 10.1 MB |
| brotli -q5 をかけたとき | 8.3 MB |

STG とブロック崩しが**それぞれ**この wasm を持つので、非圧縮だと合計約80MBです。
gzip/brotli が効くホスティングを選んでください。タワーバトルは dist 3.5MB と軽く、この問題はありません。

**3. だから「決定して初めてゲーム本体を読む」構造は崩さないほうがいい。**
右側はあくまで数MBの映像で、ゲームは押されたときに初めて読み込まれます。
プレビューを iframe で実物のゲームに差し替えると、ページを開いただけで数十MB取りにいくことになります。

## キオスクから何を引き継ぎ、何を落としたか

| | |
|---|---|
| **引き継いだ** | 左リスト＋右プレビューの2カラム / 選択行とプレビュー枠のシアンの発光 / 濃紺の地 / ドット絵アイコン / `>` のカーソル / 映像を重ねて表示だけ切り替える方式 |
| **落とした** | `?station=N` / セッションAPIのポーリング / 受付待ちロック画面 / 終了画面 / 8分アイドル / 参加賞 / `sendBeacon` / ゲームパッド / `cursor: none` / 待機デモの自動操縦 |
| **変えた** | 本文の書体（下記）/ 文字サイズ（キオスクの巨大サイズ → 画面用）/ マウス・タップを主操作に / 狭い画面で1カラムに畳む |

### 書体について

**キオスクと同じく、画面全体に美咲ゴシック（8pxドット）を当てています。**

⚠️ **文字サイズは必ず8の倍数にすること。** 半端な値だと1ドットの幅が揃わず縁がガタつきます。
`clamp()` などで可変にせず、段階で指定してください。字間（`letter-spacing`）も端数を入れないこと。

⚠️ **画数の多い漢字は小さいサイズで潰れます。** festival-kiosk では「受」が読めず、
受付画面の文言をかなに開いて回避しました（2026-09-02）。**漢字を足すときは実物で読めるか見てから。**
潰れるものは かな に開くと収まります。

## プレビューを用意する

映像は `demos/`、静止画は `previews/` に置きます。
いま入っているのは STG とブロック崩しの2本だけで、**タワーバトルとそれ以外は未収録**です。

ゲームの「放置デモ」を画面ごと録る治具が `festival-kiosk/tools/` にあります
（`record-demos.html` + `receiver.mjs`、手順は `festival-kiosk/tools/README.md`）。
⚠️ 録画中に別の窓へ切り替えると、背面のChromeは描画を止めるので真っ黒な映像が録れます。

## 実物で動かして分かったこと（2026-09-04・このシェルから3本とも起動を確認）

- 3本とも `games/` に置けば、シェルの「▶ あそぶ」からそのまま起動します。
- **ゲームからポートフォリオへ戻る動線がありません。** キオスクでは `SessionClient.return_to_shell()` が
  戻していましたが、あれは `?station=N` が付いているときだけ動く仕掛けで、ここでは無効です。
  いまはブラウザの「戻る」頼みなので、必要なら別途つくることになります。
- **タワーバトルの静的ビルドは、起動直後の画像が1枚欠けています**（`dist/characters/` が空）。
  祭り用の検証では「静的で動く」ところまでしか見ていないので、公開前に谷口さんへ確認したほうがよさそうです。
- ゲームの実タイトルは、STG が「オーレンジシューター」、タワーバトルが「ともだちたわーばとる」です。
  シェルには STG を「シューティングゲーム」として入れてあります（河村の指定）。
