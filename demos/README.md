## 加工

# 漁業・出漁サポート（順風丸）のデモ（2026-09-10）

`junpumaru.mp4`（28.5秒・1280×720）と `../previews/junpumaru.jpg` は、**実データを一切含まないダミー版**で撮影しています。

- 元アプリ `fishery/deploy/card.html` からは画面の文言と漁期カレンダーだけを使い、埋め込みデータ（海区番号・座標・漁獲・例年比）はすべて架空の値に置き換えたローカル複製で撮影。
- Firebaseと波・風の予報APIはスタブに差し替え、本番のデータベースや外部APIには接続していません。操業記録の7件と撮影中に書き込む1件もダミーです。
- ヘッドレスEdge（表示領域1440×810）をCDPで操作して録画。カーソルは録画用の疑似カーソルです。
- 流れ: 出る前（波の穏やかな日を選ぶ→狙い目）→ 海上（くらべる）→ 今年（例年比グラフ）→ 書く（1件追加）。
- 加工条件は上の4本と同じ（H.264 / CRF25 / medium / yuv420p / 30fps / faststart / 音声なし / 冒頭0.2秒・末尾0.25秒フェード / 1秒地点からposter）。
- スクリプトは `.work-video/junpumaru/`（Git対象外）。そこで `node gen_demo.js && node record.js` を実行すると再作成できます。
